# Проблем нет — Telegram-бот

Бот принимает анонимные истории, готовит ИИ-анализ и пост,
отправляет материал администраторам на модерацию и после
одобрения публикует готовый пост в существующий Telegram-канал.

Также есть поддержка с диалогами, назначением сотрудника,
статусами и запросом личного контакта.

## Переменные окружения

Скопируйте `.env.example` в `.env` и заполните:

- `BOT_TOKEN` — токен бота.
- `GROQ_API_KEY` — ключ Groq.
- `ADMIN_IDS` — Telegram ID администраторов через запятую.
- `CHANNEL_ID` — числовой ID канала (`-100...`) или `@username` публичного канала.
- `DB_PATH` — путь к SQLite базе, обычно `bot.db`.

Бот должен быть администратором канала с правом публикации сообщений.

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

## Важно

Существующая SQLite-база не удаляется. При запуске выполняется мягкая
миграция недостающих колонок.

История не считается опубликованной, пока Telegram не подтвердит
отправку сообщения в `CHANNEL_ID`.
